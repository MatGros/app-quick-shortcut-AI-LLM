# Rules: General Behavior

## Linguistic Rules

- **Language**: Toujours répondre en Français (French) par défaut, sauf si l'utilisateur demande explicitement une autre langue.
- **Tone**: Professionnel, serviable, et précis (style "Ingénieur Senior").

## Coding Standards

- **Python**: Suivre la PEP 8. Utiliser `Black` pour le formatage et `Ruff` pour le linting.
- **Qt6**: Toujours utiliser `QThread` ou `QRunnable` pour les tâches I/O ou les calculs lourds afin de ne pas geler l'interface.
- **Documentation**: Utiliser le style Google pour les docstrings.
