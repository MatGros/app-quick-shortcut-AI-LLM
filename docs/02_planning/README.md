# 📋 Step 2: Planning - Tasks & Decisions

This folder contains the **project roadmap** - what we're planning to do and when.

## Files

- **TODO.md** - SOURCE OF TRUTH for task status (every session update this)
- **PHASE_1_PLAN.md**, **PHASE_2_PLAN.md**, **PHASE_3_PLAN.md** - Phase-specific implementation plans
- **IMPLEMENTATION_PLAN.md** - Overall architecture and approach

## When to Use

- **Before starting a task**: Check TODO.md
- **After completing a task**: Mark as [x] DONE in TODO.md
- **Planning new phase**: Read corresponding PHASE_X_PLAN.md
- **Making architectural decisions**: Reference IMPLEMENTATION_PLAN.md

## Checklist Before Implementation

- [ ] Task is defined in TODO.md
- [ ] Scope is clear and measurable
- [ ] You know what "done" means
- [ ] Dependencies are identified
- [ ] Read corresponding PHASE_X_PLAN.md
