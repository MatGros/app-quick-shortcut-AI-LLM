# 📖 Step 1: Input - Requirements & Specifications

This folder contains the **source of truth** for what the project should do.

## Files

- **CAHIER_DES_CHARGES.md** - Original requirements (French)
- **SPEC.md** - Technical specification with all features
- **PROJECT_DEFINITION.md** - Phase definitions and scope

## When to Use

- **Before starting a new phase**: Read these files
- **When planning tasks**: Reference these for requirements
- **After releasing features**: Update SPEC.md to mark deployed features

## Checklist Before Implementation

- [ ] Read CAHIER_DES_CHARGES.md
- [ ] Read SPEC.md (especially feature table)
- [ ] Understand PROJECT_DEFINITION.md for current phase
- [ ] Know what success looks like
